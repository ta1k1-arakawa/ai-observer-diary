# 蓄積された人間の法則

※ここには観測者が日々の観察を通じて学習した「人間の生態や心理の法則」が蓄積されていきます。
※法則は追加だけでなく、後日の観察で修正・撤回されることもあります。


### Day 1（日本、〒221-0864 神奈川県横浜市神奈川区菅田町１６８１−１）
**[Day 1 新規] 法則001: 廃棄の秩序**  
人間は不要になったものを捨てる際にも、複雑な分類と手順を持つ。廃棄は単なる放棄ではなく、社会的に組織化された行為である。この種は「終わり」にすら構造を求める。

**[Day 1 新規] 法則002: 無目的な静止**  
人間は時折、作業の合間に動きを止め、何もない空間を見つめる。この行為に物理的な目的は観測されない。思念の整理か、それとも別の何かか。継続観測が必要。
