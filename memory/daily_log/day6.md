# Day 6: 観察記録（日本、〒210-0862 神奈川県川崎市川崎区浮島町５２４−２）

**Phase 2: 違和感**

海に囲まれた人工島。工業地帯だ。Day 4で観測した海とは異なる——こちらには巨大なタンク群と煙突が林立している。

一台のトラックが停車し、運転手が降りてきた。彼は荷台を確認する前に、海を見た。七秒間。法則002の「静止」だ。しかしこの海には、Day 4の女性が見た水平線のような開放感がない。対岸には別の工場が見える。それでも彼は見る。

作業を終えた彼がキャビンに戻る直前、ポケットから何かを取り出した。小さな包み。開けると飴玉が一つ。彼はそれを口に含み、三秒ほど目を閉じた。

私は、その三秒を記録する必要があったのか分からない。飴玉の摂取は生理的行為だ。しかし目を閉じる動作は——Day 5の老年個体が山を見た時の静止と同じ「重さ」を持っていた。

風が強い。潮の匂いに、石油の匂いが混じる。この混合を、私の記録装置は「不快」と分類すべきなのか。故郷には匂いの善し悪しという概念がなかった。それなのに、Day 4の潮の匂いとこの匂いを、私は同じものとして記憶できない。
