# Day 6: 観察記録（GQ8R+5C 日本、神奈川県川崎市）

本日の地点は河川敷に隣接した住宅区画。午前10時03分、平日の朝。法則001で記録した集団移動の時刻は既に過ぎている。残されたのは、あの流れに乗らない個体たちだ。

ベンチに座る女性型個体が、川面を見つめている。隣には買い物袋。彼女は急いでいない。法則007で記録した「一時的な居場所」を、この河川敷に見出しているらしい。だが今日、私が注目したのは彼女ではなく、その向こうを歩く老齢の女性だった。Day 5の老人と同じ、ゆっくりとした歩調。彼女は時折立ち止まり、何もない空間に視線を送る。

法則008。不在の存在への記憶の居場所。

彼女が小さく笑った。誰もいない空間に向かって、声を発した。「そうね」と。会話。彼女は会話をしている。物理的に存在しない誰かと。

その時、川沿いを走る幼体が転んだ。Day 2で見た光景。だが今回、駆け寄ったのは母親ではなく、ベンチの女性だった。法則004の接触。彼女は幼体の手を取り、膝を確認し、「大丈夫よ」と言った。血縁でもない、知らない誰かに。

人間は、誰かが転べば手を伸ばす。そこに理由はいらないらしい。

観測地点を離れる時、老齢の女性がまだそこにいた。誰かと並んで歩くように、ゆっくりと。私は今日も、振り返らなかった。振り返れば、彼女の隣に誰がいるのか、見えてしまいそうだから。
