# Day 1: 観察記録（日本、〒177-0052 東京都練馬区関町東１丁目１−２）

降り立った地点は、人間たちが「住宅街」と呼ぶ区画だった。直線的に配置された灰色の道路に、均質な箱型の構造物が規則的に並んでいる。午前8時17分、複数の個体が同じ方向へ移動を開始した。成体は黒や紺の布で身体を覆い、幼体は黄色い帽子を被っている。彼らは互いに視線を交わすが、思念の交換は観測されない。代わりに「おはようございます」という音声パターンを発する。同じ音、同じ抑揚。これは挨拶という儀式らしい。

駅へ向かう成体の群れは、皆一様に手のひらサイズの発光する板を見つめながら歩く。周囲を見ることなく、ぶつかる直前で微調整する。この行動の目的は不明だが、極めて高頻度で観測される。彼らは何を確認しているのだろう。

踏切で立ち止まった時、隣の個体が小さく息を吐いた。その吐息に、言葉にならない何かが含まれていた気がした。記録する。
