# Day 1: 観察記録（日本、〒221-0864 神奈川県横浜市神奈川区菅田町１６８１−１）

**Phase 1: 観測者**

この地点は人間の居住密度が低い。緩やかな傾斜地に、灰色の建造物が点在している。私が立っているのは、彼らが「産業廃棄物処理施設」と呼ぶ場所の近くだ。大型の移動体が規則的に出入りし、不要になった物質を運搬している。

興味深いのは、この場所に配置された人間たちの動作の精密さだ。彼らは重機を操作し、物質を分類し、記録する。不要なものを扱う作業に、なぜこれほどの秩序が必要なのか。廃棄という行為そのものが、彼らの社会システムの一部として機能していることを示している。

一人の年配の個体が、休憩時に空を見上げた。十三秒間。その視線の先には何もない。ただ冬の薄い雲があるだけだ。彼は何を探していたのだろう。作業に戻る前の、あの短い静止の意味を、私はまだ分類できない。
