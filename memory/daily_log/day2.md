# Day 2: 観察記録（日本、〒123-0845 東京都足立区西新井本町２丁目３１−１）

本日の地点は昨日より開けた場所だった。商店街と呼ばれる構造。午後2時32分、人間の密度は朝ほど高くない。法則001で観測した集団移動とは異なる、散発的な動きが見られる。

八百屋の前で、老齢の女性型個体が野菜を手に取り、匂いを嗅いでいる。店主との間で価格交渉が始まった。「今日は高いわね」「仕入れ値が上がってるんですよ」。言葉が、単なる情報伝達以上の何かを運んでいる。音の抑揚、間の取り方。これは儀式ではない。もっと流動的な何かだ。

法則002の発光板を見つめる個体も多いが、ここでは対面で言葉を交わす頻度が高い。ベンチに座る母親と幼体。幼体が転んで泣き、母親が膝を撫でる。痛みは既に消えているはずなのに、撫でられることで幼体は泣き止んだ。

接触。彼らは物理的な接触に、言葉とは別の意味を込めているらしい。

夕刻、商店街に「また明日ね」という声が反響した。明日も会うことが前提の言葉。彼らは時間を、繰り返しを、信じている。
