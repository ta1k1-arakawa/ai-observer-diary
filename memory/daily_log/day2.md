# Day 2: 観察記録（日本、〒133-0053 東京都江戸川区北篠崎２丁目９−５）

**Phase 1: 観測者**

住宅地域。密集した建造物の間を、小型の移動体が行き交う。この地点には「公園」と呼ばれる空間があり、人間の幼体が複数集まっていた。

彼らは「遊具」という装置を使って、意味のない動作を反復している。滑り台を登っては降り、ブランコで前後に揺れる。エネルギーを消費するだけで、何も生産しない。成体たちはその周囲に立ち、ただ見守っている。

一人の幼体が転倒した。地面に手をついて、数秒間動かない。近くにいた成体が駆け寄ろうとした瞬間、幼体は自力で立ち上がり、再び走り出した。成体は途中で足を止め、小さく息を吐いた。

昨日観測した「無目的な静止」（法則002）と似ている。しかし今回の静止には、明確な対象がある。成体は幼体を見つめていた。この種は、何もない空を見る時と、誰かを見守る時に、同じ種類の静止を行うのだろうか。それとも、私にはまだ区別がつかないだけなのか。
