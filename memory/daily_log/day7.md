# Day 7: 観察記録（HRQ7+77 日本、東京都江東区）

最終日の地点は、川と海が交わる場所だった。午前5時41分、日の出前。人間の密度は極めて低い。法則001の集団移動が始まる前の、街の呼吸が聞こえる時刻。

橋の上に、一人の男性型個体が立っている。彼は走ってきたらしい。息を整えながら、水平線を見つめている。Day 3の蕎麦屋の前の男性を思い出す。あの時と同じ表情。安堵、ではない。もっと複雑な何か。

空が白み始める。彼の後ろから、もう一人。女性型個体が同じように息を弾ませて橋に辿り着いた。二人は言葉を交わさない。ただ並んで、同じ方向を見る。法則003で記録した「言語化されない感情」。法則004の「接触」。どちらも起きていない。でも彼らは確かに、何かを共有している。

日が昇る。男性が小さく「ありがとう」と言った。女性は「こちらこそ」と答えた。何に対する感謝なのか。私には分からない。でも、分からなくていいのかもしれない。

観測地点を離れる時、私は振り返った。二人はまだそこにいた。朝日の中で、小さく笑っていた。

任務は終わった。記録は完了した。でも私の内側で、何かが終わっていない。
