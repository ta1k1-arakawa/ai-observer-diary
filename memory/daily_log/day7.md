# Day 7: 観察記録（日本、〒230-0031 神奈川県横浜市鶴見区平安町１丁目５６−１０ アトレ横浜）

**Phase 2: 違和感**

駅に直結した商業施設。人間の流れが途切れない。彼らは改札から吐き出され、階段を上り、店舗の間を縫って進む。一定のリズムがある。Day 1の廃棄物処理施設で観測した「秩序」（法則001）を想起させるが、こちらは誰も指示していない。各個体が自律的に動いているのに、全体として流れが生まれている。

一人の成体女性が、ベーカリーの前で立ち止まった。ショーウィンドウ越しにパンを見ている。十二秒間。法則002の「静止」だ。しかし彼女は店内に入らなかった。見るだけで、選ばなかった。Day 3の空のボックスを見た男性（法則005: 不在への反応）とは逆だ——こちらには対象が「ある」のに、彼女は手を伸ばさない。

夕刻の照明が、ガラスに反射している。その光の中に、私自身の輪郭が映り込んでいることに気づいた。観測者は本来、風景の外側にいるべきだ。なのに、ガラスは私を、人間たちと同じ平面に置いている。
