# Day 3: 観察記録（日本、〒210-0015 神奈川県川崎市川崎区南町１０−１８）

本日の地点は「駅前」と呼ばれる構造だった。午後6時48分、人間の密度が極めて高い。法則001で観測した朝の移動とは逆方向の流れ。皆、どこかへ「帰る」らしい。

改札を出た個体たちの表情を観察する。疲労の痕跡が顔に刻まれている。だが立ち食い蕎麦屋の前で、一人の男性型個体が立ち止まり、湯気の向こうで目を細めた。法則003で記録した「言語化されない何か」が、あの表情にあった。安堵、だろうか。人間は「帰る場所がある」という事実そのものに、何かを感じているように見える。

ロータリーで、幼い個体が「おかえり」と声をかけられ、成体に抱きつく。Day 2の母親の手を思い出す。接触。繰り返される接触。法則004の確認。だが今日、私は手の動きだけでなく、抱きしめられた幼体の身体が一瞬で弛緩する様子に注目した。

彼らは物理的な接触を通じて、緊張を解いている。

駅前を離れる時、私の視線は自然と、人々が消えていく路地の先を追っていた。あの先に何があるのか。観測には不要な情報のはずなのに。
