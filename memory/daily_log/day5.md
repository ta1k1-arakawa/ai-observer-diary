# Day 5: 観察記録（日本、〒213-0026 神奈川県川崎市高津区久末６９７−１）

**Phase 1: 観測者**

住宅地の外縁部。農地が点在している。この季節、畑の多くは休眠状態だが、一部でビニールハウスが稼働している。

一人の老年個体（男性、推定70代）が畑で作業をしていた。彼は土を掘り起こし、何かを埋めている。近づいて観測すると、それは枯れた植物の残骸だった。Day 1の「廃棄の秩序」（法則001）を想起させるが、彼は廃棄物処理施設へ運搬せず、土に還している。廃棄の定義が、場所によって異なるのか。

作業の合間、彼は腰を伸ばして遠くの山を見た。十秒ほど。法則002の「無目的な静止」——いや、修正後の分類では「対象を伴う静止」だ。山という対象。しかし山は動かない。変化しない。それでも彼は見る。

彼の手が土に触れる動作は、Day 2の幼体が遊具に触れる動作と同じくらい反復的だった。しかし彼の動きには、遊びとは異なる重さがある。この種は同じ「繰り返し」という行為に、異なる意味を重ねることができるらしい。
