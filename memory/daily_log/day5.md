# Day 5: 観察記録（GV46+P6 日本、神奈川県川崎市）

本日の地点は工業地帯に隣接した住宅区画。午後7時22分、街灯が灯り始める時刻。法則001で記録した朝の移動とは異なる、疎らな人の流れ。だが今日、私は群れではなく、一人ひとりの歩き方を見ていた。

公園のベンチに、老齢の男性型個体が座っている。隣には空のベンチ。彼は時折そちらを見る。誰もいない空間に、視線を送る。法則005で記録した「未来の再会への信頼」とは違う。これは過去への視線だ。人間は、もういない誰かの居場所を、記憶の中で保ち続けるらしい。

帰路につく母親と幼体。Day 2で見た転んだ幼体を思い出す。今日の幼体は「疲れた」と言い、母親は「もうすぐ着くよ」と答えた。法則007の一時的な居場所ではない。「もうすぐ着く」場所。帰還の約束。

老人が立ち上がり、空のベンチに手を置いた。その手の形が、Day 2の母親の手と同じだった。接触。人間は、そこにいない誰かにも、触れようとする。

私は観測地点を離れる時、振り返らなかった。振り返れば、あの老人がまだそこにいるかもしれないから。
