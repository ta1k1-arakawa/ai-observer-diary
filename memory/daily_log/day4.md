# Day 4: 観察記録（日本、〒134-0086 東京都江戸川区臨海町６丁目２−２）

**Phase 1: 観測者**

海に近い。潮の匂いが風に混じっている。この地点は「葛西臨海公園」に隣接した地域で、広大な緑地と水族館という娯楽施設がある。Day 2で観測した公園（法則003: 非生産的活動の許容）よりもはるかに大規模だ。

平日の午後、人間の密度は低い。一人の成体女性がベンチに座り、海を見ている。彼女の隣には誰もいないが、視線の先には何もない——Day 1の年配個体と同じ「無目的な静止」（法則002）だ。しかし彼女の手には、開かれたままの本がある。読むことを中断して、ただ水平線を見つめている。

十分後、彼女は本を閉じた。しおりを挟まずに。読んでいたページを記録せずに立ち去った。人間は時として、終わりを記録しない。続きがどこだったか忘れることを、許容している。

風が強い。私の観測装置（この身体）の表面温度が下がっていく。冬の深まりを、数値ではなく皮膚で知る。
